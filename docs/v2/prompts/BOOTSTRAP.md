# Nouveau projet

Pour un dépôt vide ou sans premier commit. Pour un projet qui existe déjà, avec ou sans historique d'assistance par IA, voir [ONBOARDING.md](ONBOARDING.md).

Copier le [prompt initial](../START-HERE.md#prompt-initial) — quarante-neuf lignes — et renseigner « Application cible » avec « nouveau projet : <description du besoin> ».

La procédure suivie ensuite est la section « NOUVEAU PROJET » de [START-HERE.md](../START-HERE.md), que l'assistant lit lui-même. Utiliser ce fichier pour éviter deux copies qui divergent.

Avant le premier usage, lire aussi [les rôles](../ROLES.md), [les skills](../../SKILLS.md) et [les fournisseurs réellement intégrés](../ADAPTERS.md). Ne pas supposer que le fournisseur de l'assistant principal est celui des sous-rôles.
